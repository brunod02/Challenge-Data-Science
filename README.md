Análisis de Rendimiento de Tiendas Latam - Challenge Data Science

📌 Descripción General

Este proyecto tiene como objetivo analizar y comparar el rendimiento de cuatro tiendas ficticias en Latinoamérica. A través de métricas clave como facturación, ventas por categoría, calificaciones de clientes, productos más y menos vendidos y costos de envío, se busca apoyar al Sr. Juan en la toma de una decisión estratégica sobre cuál tienda vender.

🎯 Objetivos del Análisis

-Determinar cuál tienda genera mayores ingresos.

-Identificar las categorías de productos más populares.

-Evaluar la reputación de cada tienda según la calificación promedio de los clientes.

-Detectar los productos más y menos vendidos por tienda.

-Comparar los costos de envío promedio para evaluar eficiencia logística.

-Formular una recomendación fundamentada sobre cuál tienda vender.
